# Changelog

## [1.2]

- Added Home Assistant browser sign-in with automatic token renewal.

## [1.1]

- Added thermostat support with target temperature and heating indicator.
- Added an onboarding window for easier setup.

## [1.0]

First stable release! 🎉

- Fixed a crash during connection recovery that could cause HomeBar to disappear from the menu bar after sleep.
- Automatically discover Home Assistant servers on the local network.
- Add a popover explaining how to create an access token.
- Add an adjustable maximum dashboard height setting.

## [0.2]

- Added automatic updates.

## [0.1]

First release of HomeBar!

- Discover Home Assistant entities.
- Support for lights, fans, plugs, and sensors.
- Customization: select, reorder and rename entities.
- Secure token storage in Keychain.
- Native UI.
