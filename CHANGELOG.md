# Changelog

## [1.0]

First stable release! 🎉

- Fixed a crash during connection recovery that could cause HomeBar to disappear from the menu bar after sleep.

## [0.2]

- Added automatic updates.

## [0.1]

First release of HomeBar!

- Discover Home Assistant entities.
- Support for lights, fans, plugs, and sensors.
- Customization: select, reorder and rename entities.
- Secure token storage in Keychain.
- Native UI.
